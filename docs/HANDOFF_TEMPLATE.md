# AI Handoff Template

Use this template when handing the project to another AI/dev agent.

## Current goal

Describe the immediate objective.

## Current repo state

Describe:

- files changed
- commands run
- tests run
- known failures
- uncommitted changes

## Architecture constraints

Confirm whether these still hold:

- cloud-first SaaS
- two-plane architecture
- strong tenant isolation
- module manifests
- modular monolith first
- event-heavy communication
- no casual superadmin access to tenant data

## What changed in this session

List concrete changes.

## Verification performed

List exact commands and outputs/summary.

## Next recommended step

Give exactly one next step.

## Risks / open questions

List anything unresolved.

## Files future agent must read first

Mandatory:

- AGENTS.md
- docs/PROJECT_STATE.md
- docs/ARCHITECTURE_BASELINE.md
- docs/AI_CHANGELOG.md

Then relevant ADRs under docs/decisions/.
